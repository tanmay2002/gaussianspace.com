# Gaussian Space
 
My personal robotics portfolio. I'm Tanmay, MSc Mobile Robotics student at Universität Bonn. This site is where I document what I'm building and researching.
 
Live at [gaussianspace.netlify.app](https://gaussianspace.netlify.app)
 
## What it is
 
An interactive landing page built around an Iron Man figure where each body part links to a project. Head is Active SLAM, torso is the G1 humanoid work, legs is the Spot Micro quadruped. Arms are coming soon once I figure out what goes there.
 
I designed the concept and wrote all the content. The HTML/CSS/JS was built with Claude since frontend isn't really my thing. I'm more comfortable in ROS2 and Python than in a browser.
 
## Stack
 
Single HTML file, no framework, no build step. Orbitron and IBM Plex Mono from Google Fonts. Hosted on Netlify, auto-deploys from this repo.
 
## Files
 
```
index.html   the whole site
CV.pdf       downloadable CV
```
 
## Updating the CV
 
Just replace CV.pdf with a new file and keep the same name. Netlify picks it up automatically.
 
## Running locally
 
Open index.html in a browser, that's it.
